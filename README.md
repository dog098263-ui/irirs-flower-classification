> A machine learning project that classifies Iris flowers into three species — *Setosa*, *Versicolor*, and *Virginica* — using multiple classification algorithms with accuracy comparison.

---

## 📌 Project Overview

This project explores the classic Iris dataset to build, evaluate, and compare multiple ML classifiers. It demonstrates the full data science workflow: from EDA and preprocessing to model training, evaluation, and visualization.

---

## 🧠 Algorithms Used

| Algorithm | Accuracy |
|-----------|----------|
| Logistic Regression | ~96% |
| K-Nearest Neighbors (KNN) | ~97% |
| Decision Tree | ~95% |
| Random Forest | ~97% |
| Support Vector Machine (SVM) | ~98% |

---

## 📊 Dataset

- **Source:** UCI Machine Learning Repository / Scikit-learn built-in
- **Features:** Sepal Length, Sepal Width, Petal Length, Petal Width
- **Target:** Species (Setosa, Versicolor, Virginica)
- **Samples:** 150 rows × 5 columns

---

- **Language:** Python 3.8+
